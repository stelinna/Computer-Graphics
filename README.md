# Computer Graphics Labs

This repository contains lab exercises for the **Computer Graphics** course, focusing on geometric fractals, 2D primitives, and 3D modeling using C++ and SFML.

## Overview

The labs cover:

- Geometric fractals  
- 2D primitives and Bresenham's algorithms  
- Wireframe modeling of 3D objects  
- 3D transformations, projections, and rotations  
- Basic event handling and visualization using SFML  

## Lab List

1. **Geometric Fractals**  
2. **2D Primitives and Bresenham's Algorithms**  
3. **Wireframe Model of a 3D Cube**  
4. **3D Wireframe Cube with Rotation and Perspective Projection**  

## Usage

- The programs are written in C++ and use the [SFML](https://www.sfml-dev.org/) library.  
- Compile using a C++ compiler with SFML linked:  
  ```bash
  g++ main.cpp -o app -lsfml-graphics -lsfml-window -lsfml-system
- Run the executable and use arrow keys to rotate the cube in 3D space
 
## Requirements
- C++ compiler (G++ or similar)
- SFML library installed
- Basic understanding of computer graphics concepts
